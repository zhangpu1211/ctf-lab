# CTFLab v0.1.1 预览版

面向 macOS 26+、Apple Silicon。此版本为预览版，不替换 v0.1.0 稳定版。

## 主要变化

- 改进 Kali 显示窗口的缩放、点击定位、输入释放、Dock 恢复与窗口重开。
- 输入恢复按节奏释放基础扫描码，优先释放 a，避免一次性发送过多释放事件。
- 改进节点管理、启动资源检查、快照、本地更新与回退及诊断功能。
- 保持剪贴板显式授权、文件传输默认关闭与靶场网络隔离。

## 当前验收范围

用户实测短程点击、拖拽释放、三轮缩放恢复正常；剪贴板关闭时双向短哨兵
不共享，开启及重连后英文、中文、多行文本一致，大文本双向哈希已核验。
最新重复 a 问题经显示客户端重连与分时释放修复后，用户确认恢复。
这些人工结果与专项测试不是跨设备、长期稳定性或所有场景的完整验收。

## 限制与安装

- 未验证真实外接屏、Mac 睡眠恢复、持续 CPU 负载和修复后的干净 35 分钟闲置闭环。
- 签名为 ad-hoc，未做 Developer ID 签名或公证；首次打开可能需系统设置手动允许。
- 不含 Kali 或靶机虚拟磁盘、密码、运行日志；镜像需用户自行导入。
- 请先备份现有配置及镜像，停止相关实例后再切换应用版本；不要重置仍需保留的 overlay。
- 正式稳定版仍保留多显示器等验收门槛，不因本次预览版发布而自动通过。

对应详细证据见 `docs/verification-release-gates-2026-10-09.md`。
