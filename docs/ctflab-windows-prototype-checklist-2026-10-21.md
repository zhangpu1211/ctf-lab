## 1. 执行前登记

由用户指定 Windows 11 x64 物理机和操作范围；记录机器代号、Windows 构建、CPU/内存/存储、固件虚拟化状态、WHP/Hyper-V/VBS、显卡/驱动/显示比例，不收集无关身份或凭据。W01 只需一个合法 Linux 样本；Windows 来宾介质到 C02 再确认。

每次执行先建立记录：任务/日期、构建提交、QEMU/Python/固件/显示组件版本及哈希、来源与许可、独立状态根、原始资产哈希、派生磁盘、实例UUID、代次、进程可执行身份/创建时间/角色、端点/网络绑定。原盘只读；不得接入物理 LAN、增加对外监听或复用用户运行盘。进程绑定必须现场重查，不能照抄旧 PID。

候选运行时目录先由来源核验和构建清单锁定；不同构建分别记录，不能将客户端可下载视为服务端具备 SPICE/TLS。测试程序只调用固定工具和白名单参数。`ctflab_platform.py` 可展示 WHPX 参数候选，但不能拿其输出替代以下实测。

## 2. 只读准备探针

获准设备上可先采集下列最小数据，结果进入本地记录，不自动上传：

```powershell
Get-CimInstance Win32_OperatingSystem | Select-Object Caption, Version, BuildNumber, OSArchitecture
Get-CimInstance Win32_Processor | Select-Object Name, AddressWidth, VirtualizationFirmwareEnabled, SecondLevelAddressTranslationExtensions
```

WHP/Hyper-V/VBS 与驱动状态按设备权限从系统界面或受控只读接口核对；读取失败记 unknown，不自动提权/启用功能/关闭 VBS。再对固定路径的候选 QEMU 检查版本、文件哈希与 `-accel help`、`-display help`、所需设备列表。列表只能说明构建能力，WHPX 是否可执行仍需下一节实际来宾探针。

主 CLI 仍含 fcntl/POSIX 依赖，不能直接作为 Windows 原型启动器。W01 应先建立独立测试驱动与平台适配注入点，再运行最小闭环；未完成传输保护前，匿名 stdio 仅限短时开发探针，不能据此验收持久控制/重连。

## 3. 逐项验证表

以下各项记录“未测/通过/失败/不适用”，不适用必须注明范围和理由；不能豁免 G0 的控制保护、归属、恢复及必要显示路径。

| 顺序/责任接口 | 操作与故障样本 | 通过证据 / 失败处理 |
| --- | --- | --- |
| 1 RuntimeBundle/HostCapabilities | 锁定构建运行最小 Linux 派生盘；标准用户、中文/空格路径；正常配置与未满足硬件条件分别检查 | WHPX 实际冷启动、控制/显示和正常停止；不可用明确拒绝，无静默 TCG；记录 CPU 默认值/显式型号的取舍，不能仅以进程存活通过 |
| 2 StateLock/PrivateStorage | 双进程争同一锁、持锁进程异常退出、重开句柄；他用户访问、junction/reparse point、非本地活动盘 | 排他/释放语义、SID/ACL/归属和链接拒绝；不以 chmod 模拟 ACL；必要时另行取得第二测试账户范围，不扩展现有访问 |
| 3 ControlTransport | 优先可重连命名管道；验证 ACL/身份/断连。不可行时单列回环 TLS+授权候选并验证构建支持 | 合法客户端重连；未授权主体、错误证书/身份被拒；目标实例/代次/磁盘绑定一致。两方案都失败则停止产品推进，禁无保护 TCP 替代 |
| 4 DisplayBackend | 锁定 SPICE 服务端/客户端，输入、焦点、100/150/200% DPI、缩放、断开再连、共享默认关闭；拒绝未授权连接 | 客体桌面/登录可操作、重连可控、访问边界有证据。SPICE 失败则记录原因，受保护 VNC 等另立同等验收，CLI/SDL 不算 G1 显示通过 |
| 5 NetworkBackend | socket sharing 或子服务一次绑定后私有就绪协议；端口抢占、父子间异常、假就绪、两实例竞争 | 监听从预约到服务持续持有；真实身份/配置匹配后才启动节点；独立回环网络，路由冲突/未知采集拒绝；不出现先检查空闲再绑定竞态 |
| 6 ProcessSupervisor | GUI/控制客户端退出、监督异常、QEMU 异常、PID 复用/身份读取失败、宿主重启 | 角色化生命周期，不因 GUI 关闭误杀 VM；监督恢复前重查身份/端点/磁盘；unknown 保留现场而非误停；不依据旧 JSON 自证归属 |
| 7 正常停止与超时 | QMP ACPI 关机、来宾迟迟不退出、重复停止、控制断线 | 停止证明成立才释放网络/端点；超时保留状态与恢复入口，强杀是另行明确操作；不得影响其他实例 |
| 8 存储/提交 | 同盘与跨卷、打开文件/扫描占用、空间不足、发布目标被并发创建、提交中断 | 原盘不变、旧文件/代次不丢；无覆盖发布、持久化顺序和恢复可重复。禁止移用 Mac renameatx_np 回退的检查后重命名作为 Windows 排他保证 |
| 9 R3 轻量共存 | 已获准安装的 Workstation 或 VirtualBox 与 QEMU 分别单独/同时运行；记录系统安全功能、响应、睡眠恢复 | 具体版本/CPU组合结果，不要求三引擎同时运行。设备或范围缺失记未测，共存从 G1 声明排除；E01 完整课程仍独立验收，不默认改安全设置 |

顺序允许在同一设备组合复用前置证据；运行时/固件/驱动/系统安全设置变化必须识别受影响项目重测。测试驱动只能操作本轮独立派生对象；故障注入前记录对象归属与恢复步骤。未绑定实例、无法证明所有权或出现其他用户资源时停止该操作并保留诊断，不扩大到宿主批量清理。
