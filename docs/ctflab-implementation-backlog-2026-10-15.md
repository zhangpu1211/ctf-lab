## 1. 执行约定

- 一次实施一个可验证切片；前置任务未验收前，不把下游 UI 作为已实现能力发布。
- 表中的“新增模块”是建议名称，文件还不存在；开始实施时核对源码并遵守 Git 白名单。
- 测试按变更范围选择。单元、合成、真实 VM、最终安装包、跨设备和完整课程分别登记，不能相互替代。
- 所有 VM 与故障注入使用本轮获准的独立实例/状态目录/派生资产；任务表不授权桌面操作、外部网络、云资源购买、镜像公开分发或软件发布。
- 完成项更新日期化验收记录和当前状态，记录提交/构建/运行时/内容哈希、设备、命令、失败/跳过、仍存现场和恢复入口。
