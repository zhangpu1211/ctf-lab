# 2026-10-09 资源档位启动基准与候选交付复核

## 范围

本轮先完成不依赖长时间闲置人工验收的工作。`tools/ctflab_benchmark.py`
对 Kali 的轻量、均衡、高性能三个档位顺序启动独立无界面实例，每档两轮。
只读复用经登记 SHA-256 校验的基盘和 RAW NVRAM，各轮使用唯一派生状态
目录、独立实验交换机和回环管理端口；公网、剪贴板和文件传输全部关闭。
结束时只停止本轮实例，不停止当前的独立桌面验收实例或用户虚拟机。

就绪必须同时满足进程存活、来宾 DHCP 和来宾 SSH 横幅响应。仅宿主端口
监听不算通过；超时保留失败，缺失样本显示未知而不是零。停止失败与残留
单独记录，整轮失败不继续启动后续档位。启动后只采样宿主进程 CPU/RSS，
它们不是来宾内存压力或桌面响应时延。

## 可重复执行

```bash
python3 -B tools/ctflab_benchmark.py \
  --app /path/to/CTFLab.app \
  --out /path/to/new-benchmark-output \
  --rounds 2 --timeout 180
```

需要本机已有可信 Kali 基盘与 NVRAM 登记、校验通过的候选 App。
输出 `startup-benchmark.json` 排他创建，已有证据不覆盖；派生状态与日志
不进入 Git。用户运行实例始终不作为性能测试对象。

## 不升级的验收范围

- 无界面 DHCP/SSH 就绪不代表图形登录、拖拽、缩放或解锁流畅。
- 不是 UTM/VirtualBox 对照试验，不据此宣称胜过其他虚拟机软件。
- 本机当前负载、缓存及同时运行的回归会影响样本，仅作本机启动基线；
  不据少量样本自动更改默认资源档位。
- 超过 30 分钟闲置后的首次唤醒、点击与解锁，按用户要求留到最后人工验收。
- 小幅鼠标唤醒补丁尚未部署到来宾；可信 SSH 主机身份、用户认证和真实
  来宾验收门槛仍有效，不通过口令读取或关闭锁屏绕过。
- 课程组合与导入取消的点击级验收、跨 Mac、多显示器、正式签名公证及
  自动更新回滚不能由本轮启动基准替代。

本轮不提交、不推送、不替换已安装 App、不发布二进制。
