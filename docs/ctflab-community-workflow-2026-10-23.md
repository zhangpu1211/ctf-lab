## 内容贡献模板

| 项目 | 必填内容 |
|---|---|
| 身份 | 课程ID、版本、标题、学习目标、预计时长 |
| 来源 | 每项镜像/样本原始来源、下载或合法准备路径 |
| 许可 | 许可文本/依据、允许的分发范围；不能再分发时仅提供合法准备说明 |
| 完整性 | 文件名、SHA-256、大小、清单版本；摘要不代替许可 |
| 环境 | 宿主/客体架构、固件、驱动、内存/磁盘预算、工具版本 |
| 网络 | 实验网段、应通/禁通矩阵、是否需要出口和理由 |
| 生命周期 | 导入、启动、业务检查、正常停止、保存继续、重置步骤 |
| 教学 | 学生任务、分级提示、教师答案单独分发、完成标准 |
| 证据 | 日期、固定运行时/资产摘要、验证命令、结果、失败/跳过及人工介入 |
| 声明 | 社区提交未验收/维护者在指定组合验收，禁止扩大支持范围 |

不接收任意宿主执行脚本作为课程自动安装入口。资料先离线校验，原始镜像只读；能启动不等于能完成课程。
