## 本轮边界

实现六项优化，不将实现与人工运行验收混写。超过 30 分钟闲置后的唤醒、
解锁和首次点击仍按用户安排留到最后。本轮不读取口令，不修改原始镜像，
不操作 UTM，不自动重启来宾，不替换已安装 App，不提交、推送或发布。

## 操作入口

```bash
./tools/ctflab preflight kali-arm64 --resource-preset light
./tools/ctflab display-diagnose kali-arm64
./tools/ctflab update status
./tools/ctflab update stage /path/to/CTFLab.app --sha256 <trusted-tree-sha256> --allow-local-candidate
./tools/ctflab update select <slot-id>
./tools/ctflab update launch
./tools/ctflab update rollback
```

GUI 在“更多”菜单提供暂存、回退与打开所选版本。暂存和选择各有确认；
旁车不是来源身份认证，用户需先确认来源可信。未显式允许本地候选时，
正式更新策略要求 Developer ID 和公证；目前公证验证链尚未完成，默认
拒绝而不是降级放行。回退只切换 App 槽位，不回退镜像或运行会话。

全局 `--state-dir` 同时限定默认更新槽位，测试面板不会把槽位写入主状态。
打开所选版本通过系统 App 启动接口传递相同状态作用域；请求打开成功
不等于新面板已就绪。可手动退出旧面板，不能混同停止虚拟机。
