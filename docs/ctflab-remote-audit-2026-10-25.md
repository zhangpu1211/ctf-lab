# 远程请求审计开发增量（2026-10-25）

承接状态第88节，补充R03的受限请求审计。新增 `ctflab_remote_audit.py`，在Runner授权/派发前写入意图、返回或抛出异常后追加结果；无实际SSH、VM或调度运行。[本轮验证](verification-remote-audit-2026-10-25.md)区分代码/故障替身与实机结果。

## 策略与操作

原Runner策略可选增加 `audit: {"root": "/绝对路径/独立私有审计目录", "max_attempts": 1000}`。容量必须为1至10000整数。审计根按规范化路径与实例根、上传缓存及租约根隔离；目录700、SQLite600，并拒绝符号链接/硬链接和非私有文件。使用既有服务普通用户在本机显式初始化：

```text
python3 -I -B tools/ctflab_remote_audit.py initialize --policy /绝对路径/policy.json
python3 -I -B tools/ctflab_remote_audit.py read --policy /绝对路径/policy.json --after 0 --limit 100
```

初始化只创建新库，已有目录不覆盖，不启动服务、VM、SSH或调度；实际Runner仍沿用普通Linux用户固定SSH命令。read是拥有私有文件权限的本机运维入口，不是新增远程协议查询动作，学生不能通过Runner读取其他主体审计。策略未启用audit时不隐式创建或记录，旧策略兼容；handshake显式返回request_audit。

## 记录与失败语义

每次调用生成独立服务端attempt UUID，客户端重复request_id不会得到审计缓存回复；原契约负责资源操作幂等。意图在独立SQLite事务提交后才进入原授权与派发调用链；不持有审计写锁跨越VM/上传操作。授权拒绝也保留审计。每条消息的原权限重读及owner/scope/租约门保持不变。

字段只保留服务端绑定的principal、规范UUID形式的request_id/instance_uuid、受限action/operation枚举、服务端UTC文本、结果类别和公开错误码；响应只提取合法operation_id。未知动作归invalid，异常文本、上传字节/摘要、原请求/响应、路径、密钥、答案、票据和任意用户字符串均不保存。服务端UUID在账本元数据中绑定。时间只是宿主UTC采样，不保证时钟可信，顺序由序号与哈希链表达。

结果returned仅表示处理函数返回，不表示授权成功、任务完成或来宾业务可用；rejected表示契约异常，unknown表示其他运行异常。提交异步任务的审计止于接收/派发返回，实际worker/来宾完成需查原operation和现场，`guest_effect_verified=false`。解析帧、读取坏策略或验证主体失败发生在Runner构造之前，当前不写入此库，仍需SSH/服务层日志；不能称完整安全事件审计。

若意图未可靠提交、账本损坏/被占用或容量耗尽，拒绝调用后端。若资源动作已返回但结果追加失败，调用方收到未知/持久化失败，意图保留为pending；不把它伪造为操作未执行，不自动重放或补记结果。崩溃同样保留pending。用户应以原请求幂等键/operation核验，不自动生成新任务重试。

容量按尝试数计算，最多两条事件/尝试；申请槽位时为已有意图预留结果空间，因此逻辑容量满后仍可完成既有意图。操作系统磁盘满仍可能使结果写入失败，逻辑容量不是文件系统硬配额。满库会拒绝所有新的审计请求，包括远程stop/cancel；本机原正常停止入口仍可由用户显式使用。没有自动绕过审计、删历史或停机；运维应监控容量，显式新建独立新库并更改策略完成换库，旧库保留。本轮没有实施换库。

## 一致性与检查点

事务内核验事件从1连续递增、前后SHA-256链、元数据head、intent/result配对和attempt索引；读取也核验全链，拒绝删尾、改内容或改索引后的新请求。最多20000事件，全链检查会随记录增长变慢，不是高吞吐集中审计系统。

read返回head_seq/head_sha256；可把已保存的检查点通过 `--checkpoint-seq N --checkpoint-sha256 SHA256` 成对传入，核对既有前缀，追加新记录不使旧检查点失效。页面每次最多100条，同时返回当前head；pending列表独立截断100条并明确标记。检查点应另存可信位置；本轮没有外部可信锚、数字签名或防篡改存储，同一服务用户若重写整库和所有本地元数据，未提供可信旧检查点时不能检测，`externally_anchored=false`。这不是不可抵赖或完整主机入侵检测。
